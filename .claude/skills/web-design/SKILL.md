# Arcates Web Design System Skill

Use this skill for every public-facing Arcates page and component.

## Visual direction
- Premium B2B technology studio aesthetic: deep navy surfaces, restrained electric blue/cyan accents, crisp typography and generous whitespace.
- Preserve Arcates brand consistency; do not introduce unrelated palettes or decorative gimmicks.
- Every section must have one clear visual hierarchy: eyebrow -> heading -> supporting copy -> primary action/content.
- Prefer subtle depth, borders and ambient gradients over heavy glassmorphism.

## Layout
- Use a shared max-width container and fluid clamp-based spacing.
- Desktop layouts may use asymmetric 2-column compositions; collapse cleanly below tablet widths.
- Keep readable text measure around 60-75 characters.
- Cards in a row should have consistent heights and aligned action areas.

## Components
- Reuse shared buttons, cards, headings, icons, header/footer and motion primitives before adding new patterns.
- Interactive states must include hover, active and keyboard focus-visible feedback.
- Keep border radius, shadows, icon containers and spacing tokens consistent.

## Quality gate
Before completing a UI change check desktop, tablet and mobile composition; heading hierarchy; overflow; contrast; focus states; reduced motion; and visual consistency with adjacent sections.
